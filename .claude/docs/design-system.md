# Design System — 2026 Ecommerce UI

## Vision

Build a premium modern ecommerce experience inspired by:
- Apple
- Stripe
- Linear
- Framer
- Shopify Horizon
- Vercel

The UI should feel:
- immersive
- premium
- lightweight
- fast
- modern
- cinematic

NOT:
- cluttered
- outdated
- dashboard-heavy
- template-looking

---

# UI Principles

## 1. Minimalism
- Large spacing
- Clear typography
- Fewer borders
- Soft shadows
- Layered depth

## 2. Motion Design
Use:
- subtle parallax
- hover animations
- smooth page transitions
- skeleton loaders
- micro-interactions

Avoid:
- heavy animations
- laggy effects
- excessive motion

## 3. 3D Elements
Use lightweight 3D:
- floating product cards
- glassmorphism
- depth layering
- gradient lighting

Avoid:
- WebGL-heavy scenes
- performance-heavy rendering

## 4. Mobile First
Design mobile-first always.

## 5. Performance
- lazy loading
- optimized images
- code splitting
- avoid large bundles

## 6. Components
Reusable components:
- ProductCard
- AnimatedButton
- GlassNavbar
- FloatingCart
- HeroSection
- BentoGrid

## 7. Color System
Use:
- neutral backgrounds
- premium gradients
- subtle accent colors

Avoid:
- overly saturated colors
- random gradients

## 8. Typography
Modern typography:
- Inter
- Geist
- Satoshi

Large readable headings.

## 9. UX
Optimize for:
- conversion
- fast checkout
- low friction
- trust building

## 10. Animation Libraries
Preferred:
- Framer Motion
- GSAP (light use only)

Avoid:
- heavy canvas rendering
- unoptimized particle systems
